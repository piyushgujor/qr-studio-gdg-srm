# QR Studio

QR Studio is a browser-only QR Code Generator & Designer built for the GDG on Campus SRM Technical Recruitment 2026-27 frontend task.

## Features
- URL, plain text, email, phone and Wi-Fi QR codes
- Live preview
- Size, margin, colors and error correction controls
- Classic, Dark and Ocean presets
- PNG download and copy-to-clipboard
- Input validation and scan-reliability warning
- Recent QR configurations persisted with localStorage
- Light/dark theme persisted with localStorage
- Responsive desktop/mobile layout

## Tech Stack
React, Vite, JavaScript, CSS, qrcode, localStorage.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

The `dist` directory can be deployed to Vercel or Netlify.

## Privacy
QR data is generated in the browser. This project does not require a backend or database. Recent configurations and theme preferences are stored locally in the browser.
